# Alans-Land-Surveying-Website

A professional, responsive website developed for **Alan's Land Surveying** to showcase the company's land surveying services, provide business information, and allow potential clients to easily get in touch.

---

## Project Overview

This project is a custom website built for Alan's Land Surveying using standard web technologies. The goal of the website is to provide an easy-to-navigate online presence that highlights the company's services, experience, and contact information while maintaining a professional appearance across desktop and mobile devices.

---

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- Git
- GitHub

---

## Development Tools

- **Visual Studio Code** is used to write and edit the website's source code.
- **Git** is used for version control to track changes throughout development.
- **GitHub** is used to host the repository, manage version history, and collaborate if needed.

## Running the Website

1. Clone or download the repository.
2. Open the project folder in **Visual Studio Code**.
3. Open `index.html` in a web browser.

No additional software or installation is required.
